# Excel for Data Analytics

This repository documents my journey of learning **Microsoft Excel for Data Analytics**, from fundamental spreadsheet operations to advanced data analysis techniques.

I'm following the Excel for Data Analytics course by **Luke Barousse** on YouTube and using this repository to maintain my practice files, exercises, notes, and projects.

## 🎯 Learning Objectives

- Develop strong Excel fundamentals.
- Learn data cleaning and data manipulation.
- Understand formulas and functions used in data analysis.
- Work with PivotTables and PivotCharts.
- Learn Power Query and M language for data transformation.
- Understand Power Pivot and data modeling.
- Learn DAX for analytical calculations.
- Build practical data analysis projects using Excel.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel 2013 | Spreadsheet operations and data analysis |
| Power Query | Data cleaning and transformation |
| M Language | Power Query formulas and transformations |
| Power Pivot | Data modeling and relationships |
| DAX | Analytical calculations and measures |
| Git & GitHub | Version control and project documentation |

**Note:** Excel 2013 Professional Plus is my primary Excel version. Power Query and Power BI Desktop will be used separately where necessary to practice features unavailable in my Excel installation.

## 📚 Learning Roadmap

### 1. Excel Fundamentals

- Introduction to Excel
- Data entry and formatting
- Basic formulas and functions
- Relative, absolute, and mixed references
- Sorting and filtering
- Conditional formatting
- Data validation

### 2. Intermediate Excel

- Logical functions (IF, AND, OR)
- Lookup functions (VLOOKUP, INDEX, MATCH)
- Text functions
- Date and time functions
- Mathematical and statistical functions
- Handling missing and duplicate data

### 3. Data Analysis

- PivotTables
- PivotCharts
- Slicers and filters
- Data summarization
- Exploratory data analysis

### 4. Power Query & M Language

- Introduction to Power Query
- Data cleaning and transformation
- Removing duplicates and handling null values
- Merging and appending queries
- Custom columns
- Understanding M language

### 5. Power Pivot & Data Modeling

- Introduction to Power Pivot
- Creating data models
- Relationships between tables
- Star schema fundamentals
- Understanding fact and dimension tables

### 6. DAX (Data Analysis Expressions)

- Introduction to DAX
- Calculated columns
- Measures
- Implicit vs. explicit measures
- Row context and filter context
- Common DAX functions
- CALCULATE and FILTER
